About Agent Mobile

A private, tool-using AI assistant that respects your time

Agent Mobile started as a full Next.js app and was rebuilt as a lean static bundle backed by edge functions. The goal: instant access to real AI with real tools, nothing to sign up for, and nothing hidden behind the curtain.

Guest by design

No accounts, no passwords, no sign-up walls. Your chats are scoped to your device with an anonymous id generated on first visit.

Keys never leave the server

AI provider keys live only in the secure backend. The app you download holds zero secrets — every model call is proxied server-side.

A chain, not a single point of failure

Five curated models across two providers, with a 483-model live catalog. If one provider rate-limits, the next answers instead.

Visible tool use

Every web search, weather lookup, calculation or file read is shown in the conversation with its result and duration.

Under the hood

FrontendNext.js static bundle — ships inside the Android APK, no runtime web server
BackendBase44 edge functions (agentChat, agentTools, agentData, agentModels, healthCheck)
AIOpenRouter + NVIDIA NIM, MiniMax-first with automatic fallback
DataDevice-scoped conversations, messages and tool-call records
OpsAutomated health check every 6 hours; CI on every push
MobileOffline-ready APK with the full UI bundled in assets
